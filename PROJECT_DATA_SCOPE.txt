Current public reviewer package: numerical predictions, archived summaries, selected numerical request counters, analysis/plotting source, generated figures/tables, provenance, and dataset access documentation. See README.rst for exact reproduction commands and boundaries.
Excluded: original video, sampled frames, sensor arrays, pretrained weights, prompts/responses, complete request caches, manuscript source and local environment credentials.
The original development repository https://github.com/xxxmaos/AdaDebate-X-ConvNeXt remains private. This public package supports independent checking of calculations from frozen predictions; it does not provide end-to-end model retraining or new inference.
