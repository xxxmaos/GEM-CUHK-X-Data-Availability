\section*{Data availability}
The study uses the HAR training release of CUHK-X---Small Model Track~\cite{jiang2026cuhkx}, with colorized depth, infrared, and thermal observations. Local download metadata identifies Hugging Face revision \texttt{ca37a2e9c6a06271309be03bbfbe16f29e40d8b4} of \href{https://huggingface.co/datasets/Kevin-Pal/CUHK-X_Small_Model_Track}{the Small Model Track release}. The 1,046-clip cohort is a project-specific selection, not the size of the full dataset. Official access information is provided on the \href{https://openaiotlab.github.io/CUHK-X/}{CUHK-X project website} and \href{https://aiot-public-dataset-cuhk-x.cuhkaiot.com/}{dataset portal}. The accompanying \href{https://huggingface.co/datasets/Kevin-Pal/CUHK-X_Small_Model_Track/blob/main/LICENSE}{CUHK-X License Version 2.0} specifies non-commercial research use under a Data Use Agreement, explicit written permission before data access, and no redistribution of the dataset. Access requests should be directed to \href{mailto:syjiang@ie.cuhk.edu.hk}{syjiang@ie.cuhk.edu.hk}.

The \href{https://github.com/xxxmaos/AdaDebate-X-ConvNeXt}{research repository} contains code, prediction records, summary results, configurations, and selected logs and reports. It does not provide the original observations or sampled frames. A separate \href{https://github.com/xxxmaos/GEM-CUHK-X-Data-Availability}{data-availability documentation repository} provides source links, version provenance, and scope information only. Both repositories are currently private and require authorized GitHub access.
