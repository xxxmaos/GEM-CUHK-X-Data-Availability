Prediction JSONL: one JSON object per clip. key is the dataset-relative clip identifier, not a filesystem path; subject is the dataset pseudonymous subject code; label is the integer ground-truth activity (0--39). predictions maps each method to its predicted class. rejected is the shared numerical rejection decision (true means rejected); confidence is the numerical ranking score where present. Accuracy over all clips includes rejected clips' internal predictions; it is not accepted-set accuracy.
Summary JSON: arms contains method metrics; evidence/cost summaries nest these under metrics. fixed means baseline wrong and method correct; broken means baseline correct and method wrong; net=fixed-broken. Macro-F1 uses all 40 classes. Paired method-to-method changes must not be confused with corrections relative to the numerical baseline.
request_metrics.jsonl: allowlisted numerical accounting from recorded attempts. condition identifies comparison arm, attempt records retries, prompt_eval_count/eval_count are server input/output token counters, seconds is request elapsed time, start_unix is request start, failed is derived from nonempty error. These are not raw prompts or model responses. Per-request timing is not end-to-end sample timing; sample latency in summaries cannot be reconstructed fully from these counters alone.
All 1,046-clip groups describe the same cohort, not separate independent test datasets. The evidence and cost samples are subsets. Class names and pseudonymous identifiers originate from CUHK-X metadata; original dataset terms remain applicable. No original sensor data is supplied.
